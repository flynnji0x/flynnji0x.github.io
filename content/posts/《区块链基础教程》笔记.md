# 区块链基础教程

> 资料来源：登链社区 [区块链基础教程](https://learnblockchain.cn/course/92)

## 区块链密码学基础概念

### 哈希函数（Hash Function）

哈希函数是区块链技术中最重要的密码学工具之一。它可以将任意长度的输入数据转换为固定长度的输出，这个输出称为哈希值（Hash Value）或摘要（Digest）。

- 特性：
  - 确定性：相同的输入总是产生相同的输出
  - 快速计算：能够快速计算出任意数据的哈希值
  - 单向性：从哈希值几乎不可能反推出原始数据（又称为"抗原像攻击"）
  - 雪崩效应：输入的微小变化会导致输出的巨大变化
  - 抗碰撞性：几乎不可能找到两个不同的输入产生相同的哈希值

比特币使用的是 SHA-256 哈希函数（Secure Hash Algorithm 256-bit），它会产生 256 位（32 字节）的哈希值。

在区块链中的应用：

- 区块链接：每个区块包含前一个区块的哈希值，形成链式结构
- 工作量证明：挖矿过程就是寻找满足特定条件的哈希值
- 地址生成：比特币地址是通过公钥的哈希值生成的
- 交易验证：快速验证数据的完整性
- 默克尔树：高效组织和验证大量交易数据

为什么哈希值不可逆？哈希函数是一个"多对一"的映射，无数个不同的输入可能对应同一个输出（虽然在实践中很难找到）。就像你无法从一个人的年龄反推出他的名字一样，因为很多人可能是同一个年龄。而且，哈希函数在计算过程中会丢失原始信息，就像把一幅画磨成粉末，你无法从粉末还原出原来的画。

### 公钥密码学（Public-Key Cryptography）

公钥密码学，也称为非对称加密，是区块链中另一个核心概念。它使用一对密钥：公钥和私钥。

- 公钥和私钥：
  - 私钥（Private Key）：一个随机生成的大数，必须严格保密，只有所有者知道
  - 公钥（Public Key）：从私钥通过数学计算推导出来，可以公开给任何人
- 公钥密码学的特性：
  - 单向性：可以从私钥计算出公钥，但无法从公钥反推私钥
  - 加密和解密：用公钥加密的数据只能用对应的私钥解密
  - 签名和验证：用私钥签名的数据可以用对应的公钥验证
- 在区块链的应用：
  - 身份认证：公钥（或者哈希）作为账户地址
  - 交易授权：用私钥对交易进行签名，证明交易是由账户所有者发起的
  - 资产所有权：谁拥有私钥，谁就拥有对应地址的资产

### 椭圆曲线密码学（ECC）

比特币和以太坊使用的是椭圆曲线数字签名算法（ECDSA），这是一种基于椭圆曲线密码学的公钥密码系统。

相比传统的 RSA 算法，椭圆曲线密码学在提供相同安全级别的情况下，可以使用更短的密钥，从而节省存储空间和计算资源。

比特币使用的椭圆曲线是 secp256k1：

- 私钥长度：256 位（32 字节）
- 公钥长度：未压缩时 512 位（64 字节），压缩后 256 位（33 字节）

### 数字签名（Digital Signature）

数字签名是公钥密码学的一个重要应用，它相当于现实世界中的手写签名，用来证明某个消息确实是由私钥持有者创建的。

- 数字签名的过程：
  - 签名过程：
    1. 对消息进行哈希运算，得到消息摘要
    2. 使用私钥对消息摘要进行加密，生成数字签名
    3. 将消息和数字签名一起发送
  - 验证过程：
    1. 对收到的消息进行哈希运算，得到消息摘要
    2. 使用发送者的公钥解密数字签名，得到原始摘要
    3. 比较两个摘要是否一致，一致则签名有效
- 数字签名的特性：
  - 不可伪造：没有私钥，无法创建有效的签名
  - 不可否认：签名者无法否认自己签过名
  - 完整性验证：如果消息被篡改，签名验证会失败
  - 身份认证：验证签名可以确认消息来源

在区块链交易中的应用——当你发起一笔比特币交易时：

```text
交易数据 = {
  from: "发送者地址",
  to: "接收者地址",
  amount: "1 BTC"
}

步骤 1: 对交易数据进行哈希
交易哈希 = SHA256(交易数据)

步骤 2: 用私钥对哈希进行签名
数字签名 = Sign(交易哈希, 私钥)

步骤 3: 广播交易和签名
广播内容 = {交易数据, 数字签名, 公钥}
```

网络中的节点收到后：

- 用公钥验证签名是否有效
- 验证公钥对应的地址是否有足够余额
- 验证通过后，将交易打包进区块

地址（Address）：区块链地址类似于银行账号，是用来接收和发送数字资产的标识符。地址通常从公钥按某种变换计算得出。只有拥有私钥的人才能使用地址中的资产。

### 默克尔树（Merkle Tree）

默克尔树，也称为哈希树，是一种树形数据结构，用于高效、安全地验证大规模数据的完整性。

默克尔树是一棵二叉树，其特点是：

- 叶子节点：存储数据的哈希值（如交易的哈希）
- 非叶子节点：存储其子节点哈希值的哈希
- 根节点：称为默克尔根（Merkle Root），代表整棵树的哈希

```text
              默克尔根
             /        \
        Hash(A+B)    Hash(C+D)
        /      \      /      \
    Hash(A)  Hash(B) Hash(C) Hash(D)
      |        |       |       |
    交易A    交易B    交易C    交易D
```

- 默克尔树的优势：
  - 快速验证：只需少量哈希值就能验证某个交易是否在区块中
  - 节省空间：轻节点只需存储区块头（包含默克尔根），无需存储所有交易
  - 数据完整性：任何交易的改变都会导致默克尔根的改变
- 默克尔证明示例：假设一个区块包含 1000 笔交易，要验证某笔交易是否在区块中：
  - 传统方式：需要下载并检查所有 1000 笔交易
  - 使用默克尔树：只需要大约 log₂(1000) ≈ 10 个哈希值

这使得轻量级客户端（如手机钱包）可以在不下载完整区块链的情况下验证交易。

区块链是由区块通过哈希值链接形成的链式数据结构：

```text
创世区块 -> 区块1 -> 区块2 -> 区块3 -> ... -> 最新区块
```

每个区块由区块体和区块头组成，而区块头通常会包含所有交易的默克尔树根哈希。

## 比特币的诞生

### 诞生的背景

2008 年，全球金融危机席卷而来。雷曼兄弟破产，美联储开启量化宽松，向市场注入大量货币。人们对政府和中央银行滥发货币的担忧与日俱增。

正是在这样的背景下，一位化名为"中本聪"（Satoshi Nakamoto）的神秘人物，提出了一个大胆的设想：创造一种不依赖任何中心化机构的电子货币。

### 比特币白皮书的发布

2008 年 10 月 31 日，中本聪在密码学邮件列表（Cryptography Mailing List）中发布了一个链接，指向一篇仅有 9 页的论文：[《比特币：点对点的电子现金系统》](https://bitcoin.org/bitcoin.pdf)（Bitcoin: A Peer-to-Peer Electronic Cash System）。

革命性的想法：

> "一个完全通过点对点技术实现的电子现金系统，它使得在线支付能够直接从一方发起并支付给另一方，而不需要通过任何金融机构。"

### 创世区块的诞生

2009 年 1 月 3 日，中本聪在自己的电脑上挖出了比特币的第 0 个区块，史称"创世区块"（Genesis Block）。这一刻，比特币网络正式启动。

中本聪在创世区块中写入了一段永久铭刻的信息：

> **The Times 03/Jan/2009 Chancellor on brink of second bailout for banks.**
> （2009 年 1 月 3 日，财政大臣正处于实施第二轮银行紧急援助的边缘）

这是当天英国《泰晤士报》的头版标题。这句话不仅证明了比特币的诞生时间，更表达了对传统金融体系的质疑，以及对新型货币系统的期待。

创世区块挖出后，中本聪获得了 50 个比特币的挖矿奖励。这 50 个比特币，成为了人类历史上第一批通过算法产生的数字货币。

### 比特币如何运作

比特币最核心的创新，是解决了一个困扰计算机科学家多年的难题：**如何在一个去中心化的网络中，让所有人对账本达成一致？**

中本聪的答案是：**工作量证明（Proof of Work）**。

### 工作量证明：用算力保证安全

比特币网络中，每隔约 10 分钟就会产生一个新的区块，记录这段时间内的所有交易。但是，谁有权利创建这个区块呢？比特币的规则是：**谁先解出一道数学难题，谁就获得记账权。**

率先解出难题的节点，可以：

1. 创建一个新区块，将交易打包进区块链
2. 获得区块奖励：最初是 50 个比特币，之后每约 4 年减半一次（2024 年已减半至 3.125 个）
3. 获得这个区块内所有交易的手续费

这个寻找答案的过程被形象地称为"挖矿"（Mining），而参与的节点被称为"矿工"（Miner）。

### 比特币发行总量

比特币的所有供应量都来自挖矿奖励。初始奖励是每个区块 50 个比特币，之后每隔 21 万个区块（约 4 年）减半一次。

### 区块链：不可篡改的账本

每个区块不仅包含交易数据，还包含前一个区块的"指纹"（哈希值）。这样，所有区块就像链条一样环环相扣，形成了"区块链"。

### 货币的本质：共识

比特币具备货币的所有特性：

- 可分割性：一个比特币可以分割到小数点后 8 位（0.00000001 BTC，称为 1"聪"）
- 可携带性：只需一串私钥，就能掌控任意数量的比特币
- 耐久性：只要区块链存在，比特币就永远存在
- 稀缺性：总量恒定在 2100 万枚，永不增发
- 可验证性：任何人都可以验证比特币的真伪和所有权

### 更深层的价值：自由与抗审查

对很多人而言，比特币的价值不仅在于投资回报，更在于它代表的理念：

- 金融自主权：无需银行账户，无需他人许可，任何人都可以使用比特币
- 抗审查性：没有任何机构能冻结你的比特币账户
- 透明性：所有交易记录公开可查，但不与真实身份绑定
- 去中心化：不依赖任何单一实体，系统由全球成千上万的节点共同维护

### 比特币的去中心化特性

去中心化体现在：

- 无需权威背书：比特币不需要任何政府或机构的认可
- 点对点网络：没有中心化的服务器，所有节点地位平等
- 分布式账本：区块链数据存储在全球数十万个节点中
- 公开透明：任何人都可以下载完整的账本，验证所有交易
- 无需许可：任何人都可以创建比特币地址，发起转账，参与挖矿
- 共同治理：没有单一管理者，所有节点共同维护网络

去中心化也面临挑战：矿池的出现、交易所的作用、开发者的影响。

## 比特币是如何运行的

### UTXO 模型

UTXO：Unspent Transaction Output，未花费的交易输出。

- UTXO 其实是包含了一定数量的比特币以及花费这些比特币时所需满足的条件（叫做"锁定脚本"（locking script））
- UTXO 是不可分割的最小的交易单元
- 钱包实际是一个管理私钥（生成，存储，签名）的工具

### 交易过程

主要有这么几个阶段：

1. 发起交易及交易签名
2. 节点验证交易有效性
3. 使用工作量证明挖掘新区块

### 发起交易及交易签名

一笔比特币交易主要由以下元素组成：

- 交易输入：它们指向之前的交易创建的 UTXO，通常钱包会收集当前可用的 UTXO 集合作为交易的输入
- 交易输出：表明多少比特币会锁定到哪些地址，即生成新的 UTXO
- 签名：用私钥来解锁交易输入的 UTXO

创建比特币交易是在钱包内完成的，而不是在节点上，因此可以在离线的情况下创建交易。交易创建后，通过比特币节点发送到比特币网络中。

### 节点验证交易有效性

- 无论交易来自哪里，都得先被节点的交易池（mempool）接受
- 交易池就是未确认交易的缓存，以便矿工从中挑选出手续费最高的交易，打包到区块中

### 使用工作量证明挖掘新区块

矿工从交易池中找出最优的一组交易（在一个区块限制下，手续费收益最大），给这组交易创建默克尔树，然后不断的执行暴力哈希运算，以求解出满足 Hash 目标值的 nonce 值：

```text
SHA256(SHA256(version + prev_hash + merkle_root + ntime + nbits + nonce )) < HASH 目标值
```

- version：block 的版本
- prev_hash：上一个 block 的 hash 值
- merkle_root：需要写入的交易记录的 hash 树的值
- ntime：更新时间
- nbits：当前难度

## 理解区块链核心技术

### 什么是区块链

- 狭义上说区块链是一种区块通过 Hash 方式形成的链式结构
- 广义上讲区块链定义为一个共享的、不可篡改的账本，用于记录网络中的交易和跟踪"资产"流转

**区块是区块链中的数据存储单元。** 区块由参与网络的节点独立生成，每一个区块中存储了一组交易信息，这些交易信息的哈希数据作为默克尔树节点存储，每个区块同时存储前一个区块的哈希信息，因此区块就通过哈希信息链接起来，形成区块链。

### 区块链的三个关键元素

- 分布式账本技术
- 不可篡改的记录
- 智能合约

### 智能合约

2013 年，Vitalik 提出了以太坊，创造性引入智能合约。智能合约是区块链上可执行的代码，用户可以根据自己的业务需要上传自己的代码到以太坊上，由以太坊的节点来执行，极大的丰富了区块链的执行程序能力。

智能合约名称由来：智能合约是链上的程序，为什么叫智能合约呢？"合约"是取材自现实中的合约，是想强调链上的程序可以按协议规则执行，就像法律条款一样。"智能"主要是强调不受干预的可自动执行。

### 区块链共识机制

常见的共识机制：工作量证明（PoW）、权益证明（PoS）。

#### 工作量证明（PoW）

- 优点：
  - 被认为是最安全可靠的共识机制
- 缺点：
  - 消耗大量计算能力和电能
  - 矿工抱团，形成超过 50% 算力，可以对链发起 51% 算力攻击

#### 权益证明（PoS）

PoS（Proof of Stake）：节点争夺记账权依靠的不是算力而是权益（占比），权益通常是通过质押数字货币计算而来。在 PoS 共识中，节点被称为验证者。

- 优点：
  - 不需要消耗大量能量
  - 出块稳定，通常吞吐量表现都更加优异
- 缺点：
  - 不够成熟
  - 参与 PoS 共识需要质押货币，需要当前的验证者确认

### 区块链不可能三角

不可能三角是去中心化（Decentralization）、可扩展性（Scalability）、安全性（Security），三者不可兼得，只能得其二。

- **去中心化**：指的是节点的去中心化程度，节点越多越分散越去中心化
- **可扩展性**：指的是区块链的处理交易性能，每秒可处理交易越多越具备可扩展性
- **安全性**：指的是整个区块链网络的安全，攻击成本越高越安全

### 区块链分叉

- 硬分叉：用新的协议构建新的区块
- 软分叉：
  - 升级后的新节点会按照新规则验证区块
  - 未升级的旧节点仍然可以接受新节点产生的区块（因为新规则是旧规则的子集）
  - 但新节点会拒绝不符合新规则的区块
- 瞬时分叉

## 以太坊：可编程的区块链

2013 年，当时 19 岁的 Vitalik Buterin（维塔利克·布特林）发布了以太坊白皮书，提出了一个具有图灵完备编程语言的区块链平台。

2015 年 7 月 30 日，以太坊创世区块诞生，正式上线。

- 比特币就像**数字黄金**，专注于价值存储和转移
- 以太坊则像一台**全球共享的计算机**，可以运行各种去中心化应用

### 智能合约

智能合约是一段部署在区块链上的代码，它可以自动执行、控制或记录相关事件和行动。一旦部署到区块链上，智能合约就会按照预设的规则自动运行，不受任何人的控制。

智能合约的特点：

- 自动执行：条件满足时自动执行，无需人工干预
- 不可篡改：一旦部署，代码不能被修改（除非设计了升级机制）
- 透明公开：任何人都可以查看合约代码和执行结果
- 去中心化：运行在分布式网络上，不依赖中心化服务器
- 可信执行：执行结果由网络共识保证，无法被单方面篡改

### 智能合约的实际应用

- 金融合约：借贷、保险、衍生品交易

### Gas 机制

Gas 机制的作用：防止滥用、激励验证者、资源定价。

Gas 的基本概念：

- Gas
- Gas Price
- Gas Limit
- Gas Used

交易费用 = Gas Used × Gas Price

2021 年 8 月，以太坊实施了 EIP-1559 升级，改变了 Gas 费的计算方式：

- **Base Fee（基础费用）**：由网络根据拥堵程度自动调整，这部分费用会被销毁（burn），使 Gas 费更可预测
- **Priority Fee（优先费用）**：用户给验证者的小费，鼓励优先打包

## 不同类型的区块链

### 公链（Public Blockchain）

公链应该具备：

1. 开放所有源码
2. 节点位置分布分散
3. 足够的非关联方节点（规避节点相互勾结）
4. 治理决策是否开放

公链的典型案例：比特币、以太坊、Solana、BSC（币安智能链）。

公链的应用场景：加密货币交易、DeFi（去中心化金融）、NFT 市场、DAO 组织、跨境支付。

### 联盟链（Consortium Blockchain）

联盟链的典型案例：

- Hyperledger Fabric
- R3 Corda
- Quorum
- 蚂蚁链（AntChain）
- 长安链（ChainMaker）

联盟链的应用场景：供应链金融、跨境交易、医疗数据共享、食品溯源、数字身份认证、票据交易。

### 私链（Private Blockchain）

特点：访问限制、节点准入、数据隐私、中心化管理。

私链的典型案例：企业内部审计系统、医疗数据管理、内部供应链追踪。

私链的应用场景：企业内部审计、数据库管理、内部积分系统、研发环境。

### 混合解决方案

- 公链 + Layer2 或侧链
- 联盟链 + 公链锚定
- 多链架构

## 区块链扩容

最主要的扩容思路是分层扩容：

- Layer1 负责安全性
- Layer2 负责性能

### Layer1 的扩容尝试

- 扩大区块大小
- 分片（Sharding）
- 高性能共识机制：
  - Solana：使用历史证明（PoH）+ PoS，理论 TPS 可达 65000
  - BNB Chain（币安智能链）：使用 PoSA 共识，由 21 个验证节点维护，TPS 约 160

### Layer2 扩容方案

**核心思想**：将原本在 Layer1 上执行的交易放到 Layer2 上处理，减轻 Layer1 的负担，然后 Layer2 定期与 Layer1 通信，将交易批量提交到 Layer1。这样既能享受 Layer1 的安全性，又能大幅提升交易处理能力。

- 比特币闪电网络
- 以太坊的 Rollup 方案：Rollup 的核心思想是——**由 Rollup 层负责执行交易，然后将许多笔交易压缩成一笔交易批量提交给以太坊**
- Rollup 的两种类型：
  - **Optimistic Rollup（乐观 Rollup）**，主要项目：Arbitrum、Optimism、Base
  - **ZK Rollup（零知识证明 Rollup）**，主要项目：ZKSync Era、Polygon zkEVM、Scroll、StarkNet

### 以太坊 Rollup 为中心路线图

路线图的核心思想是：**以太坊主网专注于提供安全性和数据可用性，而将交易执行和计算主要交给 Layer2 Rollup 来完成**。

相比分片需要对以太坊进行更深层的架构改造，Rollup 方案可以在现有技术框架下实现扩容，同时又可继承以太坊主网的安全性。

### 侧链及其他方案

侧链和以太坊 L2 解决方案的主要区别是：**Layer2 继承以太坊主网络的安全性，而侧链依赖于自己的安全性**。

### 互联网演进

- Web2.0：能读能写
- Web3.0：能读能写能拥有

### 去中心化存储

#### IPFS 协议

IPFS 的目标是取代 HTTP 去构建一个更好的去中心化的 Web（DWeb）。现有的 HTTP 网络服务是基于 IP 寻址的，就是通过 IP 找到内容所在的服务器，然后再与服务器交互。而在 IPFS 的网络里是根据**内容寻址**的，我们上传到 IPFS 的文件都会产生哈希值，无需知道文件存储在哪里，通过哈希值就能够找到这个文件。

## 区块链应用场景

### 金融服务

- 支付、跨境支付与结算
- 稳定币支付
- 资产数字化/代币化

### 原生链上资产发行

原生链上资产的主要类型：

1. **治理代币（Governance Token）**：用于协议治理投票，持有者可以参与项目的决策
2. **实用代币（Utility Token）**：用于访问特定服务或功能，如支付网络费用、获取服务权限
3. **社交代币（Social Token）**：个人或社区发行的代币，代表创作者的品牌价值或社区成员资格
4. **链上合成资产（Synthetic Assets）**：通过智能合约创建的衍生品，追踪其他资产的价格
5. **meme 币和社区驱动代币**：由社区驱动的文化代币

实际应用案例：Uniswap 的 UNI 治理代币、Chainlink 的 LINK 实用代币、ENS 的 ENS 治理代币、Rally 社交代币平台、Friend.tech 社交代币、Synthetix 合成资产、GMX 的 GLP 流动性代币、Dogecoin 和 Shiba Inu。

## Web3 安全指南

### 私钥安全

谁拥有私钥，谁就拥有资产。

- 私钥丢失 = 资产永久丢失（没有"忘记密码"功能）
- 私钥泄露 = 资产被盗（无法追回）
- 区块链交易不可逆 = 转错了无法撤销

### 私钥管理的最佳实践

1. 永远不要分享私钥或助记词：
   - 不要截图保存
   - 不要通过微信、QQ、邮件发送
   - 不要保存在云盘、笔记软件中
   - 不要告诉任何人，包括自称"客服"的人
   - 没有任何正规项目或交易所会向你索要私钥
2. 安全地备份助记词
3. 使用硬件钱包
4. 实施多重签名
5. 使用不同的钱包：
   - 热钱包
   - 冷钱包

### 常见骗局与防范

- 钓鱼网站
- 假冒空投
- 虚假客服
- 庞氏骗局/资金盘
- Rug Pull（卷款跑路）
